# data/

Runtime data files — not committed; generated by the sieve scripts.

| File | Generates from |
|------|---------------|
| `exceptional_primes.csv` | `src/methods/phi_sieve.c` or `alpha0-ponti` |
| `exceptional_primes.txt` | same — required by `src/verify/verify_s14.py` |
| `certified_hashes.json`  | `src/tier1/runner.py` writes; tier2/tier3/manifest sections |

To populate locally:
```bash
# From alpha0-ponti (canonical):
cp /path/to/alpha0-ponti/data/exceptional_primes.csv data/
cp /path/to/alpha0-ponti/data/exceptional_primes.txt data/   # or extract from csv
```
